# Cognifyz Restaurant Data Analysis

Data Science internship project at **Cognifyz Technologies**, covering exploration, analysis, feature engineering and rating prediction on a restaurant dataset.

## Tasks

**Level 1:** Data exploration and preprocessing · Descriptive analysis · Geospatial analysis

**Level 2:** Table booking and online delivery · Price range analysis · Feature engineering

**Level 3:** Predictive modeling (Linear Regression, Decision Tree, Random Forest) · Customer preference analysis · Data visualization

## Structure

```text
├── Dataset/
├── Level_1/
├── Level_2/
├── Level_3/
└── README.md
```

## Tech Stack

Python · Pandas · NumPy · Matplotlib · Seaborn · Folium · Scikit-learn

## How to Run

```bash
git clone https://github.com/sukanyabasu-coder/Cognifyz_Restaurant_Data_Analysis.git
pip install pandas numpy matplotlib seaborn folium scikit-learn
```

Open the notebooks in Jupyter or Colab and run them level by level.
